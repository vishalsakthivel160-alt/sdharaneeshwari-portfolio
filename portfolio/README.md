# Portfolio — S. Dharaneeshwari

Personal portfolio website. Frontend and backend are kept fully separate.

## Structure

```
/frontend   React app (Create React App structure)
/backend    Node.js + Express API
```

## Setup

### Backend
```
cd backend
npm install
cp .env.example .env
npm run dev
```
Runs on http://localhost:5000 (health check: `/api/health`)

### Frontend
```
cd frontend
npm install
npm start
```
Runs on http://localhost:3000
